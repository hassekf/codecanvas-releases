## What each thing is

- **Project**: a folder on your disk. Every agent in the project is born inside it, and each project
  has its own panels, agents, theme and connections. See [choosing the project](escolher-o-projeto).
- **Canvas**: the space where the panels live. It has no edges, and panels stay where you left them.
  See [panning and zooming](mover-e-dar-zoom).
- **Panel**: everything that shows up on the canvas. An agent is a panel, and so are the browser,
  Git, a file, tasks, notes and your camera. See [panels and the desk](os-paineis-e-a-mesa).
- **Agent**: the agent program running in a real terminal inside the panel. See
  [what an agent is](o-que-e-um-agente).
- **Work area**: the tabs within one canvas, for separating subjects. See
  [work areas](areas-de-trabalho).

## The keys

| Key | What it does |
|---|---|
| `⌘K` | Goes to any panel, agent or project, and creates what doesn't exist |
| `⌘N` | A new agent |
| `⌘T` | A terminal with no agent |
| `⌘⇧E` | The shelf: everything open in this canvas |
| `⌘1`…`⌘9` | Switch project |
| `⌥C` | Turns the conversation with Nina on and off |
| `⌥X` | Hold and tell the canvas to do something |
| `⌥D` | Hold and dictate inside an agent |
| `⌥F` | Flips the panels and shows each agent's summary |
| `⌘,` | Settings |

All of them can be changed in Settings → Shortcuts. See [search and commands](busca-e-comandos).

## Where the settings live

- **For the whole app**, at `⌘,`: voice, shortcuts, interface, providers, agents, notifications,
  costs, licence. See [alerts and sounds](avisos-e-sons) and [agent settings](ajustes-agentes).
- **For this project**, in the canvas menu: the folder, the skills, the MCP servers, the browser, the
  appearance, the announcements and the integrations. See [project settings](ajustes-projeto) and
  [appearance](aparencia).
